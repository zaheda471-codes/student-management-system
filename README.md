# Student Management System

## Project Overview
A menu-driven Student Management System
developed using Python.

This application allows users to manage
student records efficiently.

## Features
- Add student details
- View all student records
- Search students using roll number
- Update student information
- Delete student records
- Store records permanently using JSON
- Input validation
- Prevent duplicate roll numbers

## Technologies Used
- Python 3
- JSON
- VS Code

## Concepts Used
- Functions
- Lists and Dictionaries
- Loops and Conditional Statements
- File Handling
- Exception Handling

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run student_management.py.
4. Follow the menu instructions.
